# WowRaidSetupTool

Windows 10 桌面版 WOW 团队活动排班工具。

## 当前状态

项目已完成首版可用原型，包含：

- 软件设计说明文档
- PySide6 桌面程序骨架
- SQLite 数据库初始化与迁移
- 基础领域模型
- Buff/Debuff 目录初版
- 自然人与角色管理
- 活动 / 班次 / 模板管理
- 排班工作台初版
- 报名池与手动排班修正初版
- 导入导出与字符串交换初版

## 本地运行

```bash
pip install -r requirements.txt
python src/main.py
```

## 当前已实现

- 自然人新增、编辑、删除
- 自然人默认可参加活动日设置（Fri/Sat/Sun/Mon）
- 角色新增、编辑、删除
- 角色职业设置
- 角色职责设置（Tank / Healer / DPS）
- 角色启用/停用状态
- 阵容模板新增、编辑、删除
- 模板人数校验（总人数必须等于 25）
- 活动新增、编辑、删除
- 班次新增、编辑、删除
- 班次绑定模板
- 周五/六/日/一批量生成班次（14 天窗口）
- 排班工作台活动/班次联动
- 自动排班初版（按模板优先补足 T/H/D）
- 阵容人数统计
- Buff / Debuff 覆盖检查联动刷新
- 排班结果持久化保存
- 手动添加报名
- 报名池转入排班
- 手动移除报名
- 手动移除排班成员
- 锁定 / 解锁已排角色
- 自动排班保留已锁定角色
- 名单 JSON 导入导出
- 活动班次字符串导入导出
- 报名字符串导入导出

- 导入导出界面改为班次下拉选择

## 推荐试用流程

1. 在“自然人与角色”创建基础成员与角色。
2. 在“阵容模板”创建 25 人模板，例如 2 / 5 / 18。
3. 在“活动与班次”创建活动，并批量生成周五/六/日/一班次。
4. 在“导入导出”导出活动班次字符串。
5. 其他人导入后进行报名，再导出报名字符串。
6. 组织者导入报名字符串。
7. 在“排班工作台”执行自动排班。
8. 锁定关键角色，再次自动补排。
9. 导出排班文件或排班字符串。

## 已知限制

- 导入去重目前是基础规则，不是严格主键合并策略。
- 自动排班仍为首版规则算法，尚未实现更高级公平性与覆盖优化。
- Buff / Debuff 目录仍需继续扩充到更完整的 WotLK 规则集。
- 排班表暂未提供反向导入。
- 报名流程目前以组织者本地整合为主，尚未做“玩家模式”单独界面。
